# 智码工坊 · 任意题目多语言代码生成器

在线访问：**https://jackeason-3m.github.io/zhima-code-forge/**

输入任意自然语言题目，选择编程语言，即时生成完整可运行代码，并附带解题思路、复杂度与示例输入输出。

- 支持 10 种语言：Python、JavaScript、TypeScript、Java、C、C++、C#、Go、Rust、PHP
- 内置 16 个算法 × 10 种语言，共 160 份模板
- 本地知识库离线可用；可选接入 OpenAI / DeepSeek / 通义 / 智谱 / 本地 Ollama
- 纯静态单文件站点，无需后端与数据库
- 多语言对比、代码高亮、复制、下载、历史记录、深浅主题、移动端适配

## 说明

本仓库只包含构建后的单文件 `index.html`，用于 GitHub Pages 部署。完整源码、自动化测试与课程设计报告保存在本地项目中：

- `assets/`：样式、数据、160 份代码模板、生成引擎与交互逻辑
- `tools/`：单文件构建脚本、知识库测试、模板运行测试
- `docs/课程设计报告.md`：课程设计报告

## 本地运行

下载 `index.html` 后双击即可使用；或使用任意静态服务器托管。
