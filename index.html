def bubble_sort(nums):
  arr = nums[:]
  for i in range(len(arr) - 1):
    for j in range(len(arr) - 1 - i):
      if arr[j] > arr[j + 1]:
        arr[j], arr[j + 1] = arr[j + 1], arr[j]
  return arr

ABOUT THE PROJECT

关于这个项目

「智码工坊」是为 人工智能课程期末作业 设计的作品。它把“自然语言 → 算法识别 → 多语言代码”这条链路做成了一个 可以直接演示、也可以部署到公网的网站。核心目标不是替代程序员，而是展示 AI 技术如何辅助编程学习： 同一道题目，在不同语言中应当如何表达。

系统采用「本地知识库 + 可选大模型」双引擎：断网时用内置模板完成稳定演示；联网并配置接口后，可以处理任意开放题目。 所有生成结果都包含思路、复杂度与示例，方便对照学习。
